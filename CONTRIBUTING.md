# Contributing to Mechana™

Thank you for helping improve Mechana. Keep changes focused, preserve the
architecture boundaries in [AGENTS.md](AGENTS.md), and follow the repository's
build and documentation conventions.

## Development workflow

1. Read `AGENTS.md` and the relevant project-brain documents before editing.
2. Add tests or documentation appropriate to the change.
3. Run `mvn verify` from the repository root.
4. Keep commits focused and explain user-visible or architectural effects in the
   pull request.

New hand-authored source and script files must include the standard Apache
License 2.0 header described in `AGENTS.md`. Do not add it to generated files,
binaries, SVGs, JSON/YAML, or assets where comments are unsuitable.
