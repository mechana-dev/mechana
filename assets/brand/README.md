# Mechana Brand Assets

Canonical Mechana brand package.

## Canonical mark

The symbol is a coral hexagon containing three nodes joined by **two diagonal connectors only**.

There is intentionally **no horizontal cross-piece**.

## Canonical colors

- Coral: `#FF6B6F`
- Ink: `#0D1117`
- Muted gray: `#6B7280`
- Light gray: `#E5E7EB`
- White: `#FFFFFF`

## Typography

Preferred family: **Sora**.

- Wordmark: extra-bold (`850`), tightly tracked
- Tagline: semibold (`650`)

SVG files include practical system fallbacks.

## Usage rules

- Do not add a horizontal cross-piece.
- Do not distort, rotate, bevel, shadow, or apply 3D effects.
- Preserve clear space around the mark equal to at least half the diameter of a lower node.
- Use a color mark on standard digital surfaces.
- Use `mechana-mark-monochrome.svg` where only one color is permitted.
- Use `favicon.svg` for the website favicon.
