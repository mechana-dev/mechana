# Mechana Brand Assets

This package contains the canonical Mechana logo system.

## Canonical symbol

A coral hexagon enclosing three nodes connected by **two diagonal lines only**.
There is intentionally **no horizontal cross-piece**.

## Canonical colors

- Coral: `#FF6B6F`
- Ink: `#0D1117`
- Muted gray: `#6B7280`
- Light gray: `#E5E7EB`
- White: `#FFFFFF`

## Typography

Preferred: **Sora Bold** for the wordmark and **Sora Medium** for the tagline.
Fallbacks are embedded in each SVG.

## Usage rules

- Do not add a horizontal cross-piece.
- Do not distort, rotate, bevel, shadow, or add 3D effects.
- Preserve clear space equal to at least half the diameter of a lower node.
- Use the monochrome SVG for one-color applications.
- Use the app-icon variant for favicons and compact UI icons.
