# Worker management

Last reviewed: 2026-08-04

Worker process lifecycle is operational tooling, not scheduler placement. The
optional `worker-host-agent` runs on each controlled machine. The optional Swing
`worker-control-app` connects to an explicitly configured agent over HTTP/JSON.
An IP address alone does not provide process-creation authority.

## First-version contract

- `GET /api/v1/health` reports agent reachability.
- `GET /api/v1/workers` reports requested count, live managed-child count, state,
  diagnostics, IDs, PIDs, and start times.
- `POST /api/v1/workers/start` with `{"count":N}` adds only the deficit needed to
  reach N live children. It never duplicates already-live managed workers and
  rejects counts above the configured maximum.
- `POST /api/v1/workers/stop` gracefully terminates every currently tracked child,
  waits the configured timeout, then forcibly terminates survivors.

Agent-generated worker IDs begin with the configured `machine-name` (or a
normalized local hostname by default), followed by a UUID, so scheduler and
dashboard views retain host identity without treating it as proof of trust.

Management routes require a shared bearer token whenever the agent binds beyond
loopback unless `allow-unauthenticated=true` explicitly enables development mode.
Loopback may omit a token for local testing. Worker IDs are generated by
the agent, output is written beneath the configured working directory, and no
request data is interpolated into a shell command.

Tracking is intentionally process-local. Workers launched outside the agent are
not discovered or stopped, and an agent restart does not adopt surviving children.
Shared-token mode stores the token in a local properties file and sends it over
plain HTTP. Unauthenticated development mode allows anyone who can reach the port
to start and stop workers. Use either mode only on a trusted LAN/tailnet with a
host firewall. TLS, OS credential
storage, token rotation, service installers, durable adoption, and audit logging
remain production-hardening work.
